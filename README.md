# Clear Creek Neighbors

A private, offline phone app to remember who lives in each unit at **Clear Creek Townhomes**
(Logan, UT) — on a recreated interactive map, with a sale-status overlay.

- **All data stays on your device** (IndexedDB, with a localStorage fallback). Nothing is uploaded.
- Single self-contained file — no build step, no server, no accounts.

## Files

| File | What it is |
|------|-----------|
| `index.html` | The whole app. Open it in a browser; that's it. |
| `data/lots.json` | All 154 lots — lot #, block, address, sale status, price, geometry. |
| `data/basemap.svg` | The recreated plat base map (streets, sidewalks, green space). |
| `data/overlay.json` | Map decoration: street-label positions, trees, parking-stall lines. |
| `.claude/launch.json` | Convenience config to preview locally over HTTP. |

## Using it on your phone

1. Open `index.html` from a URL your phone can reach (the private Claude artifact, or any
   host you serve it from).
2. In Safari/Chrome: **Share → Add to Home Screen**. It then opens full-screen like an app.
3. Tap any unit → add the people and pets who live there (name, optional photo, notes).
4. **Map / List** toggle switches between the plan view and a scannable list.
   **Neighbors / For sale** toggle recolors the map.
5. Search by neighbor name or street address.
6. **☰ menu → Save a backup** downloads all your neighbors as a file. Do this before clearing
   your browser or moving to a new phone; **Restore from backup** loads it back.

## Updating sale status

Sale status is a dated snapshot (baked in from the builder's live map). To refresh it:
**☰ menu → Update sale status**, which includes a bookmarklet + paste flow. Your neighbors and
photos are never touched — only the sale status changes.

## Rebuilding `index.html`

`index.html` is generated by injecting `data/lots.json` and `data/basemap.svg` into a template.
The data was captured from the builder's PlatWidget embed
(`platwidget.com`, `sp=8406477132aa9212d423e56a84692506`) on 2026-08-14.
